# VALIDATEX Project Memory & Rules

## Confidential Document Safeguards
- **CRITICAL DIRECTIVE**: NEVER stage, commit, or push `VALIDATEX_PRD.md`, `VALIDATEX_Antigravity_PRD.md`, or any PRD/specification markdown file to GitHub.
- PRD documents must strictly remain local on the machine and excluded via `.gitignore`.
- Before every commit and push, verify that no PRD files are in the git index (`git status` / `git diff --cached`).
